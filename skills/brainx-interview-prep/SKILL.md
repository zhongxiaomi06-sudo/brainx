# 面试准备

调用 `brainx_interview_prep` 获取有界问题；只有需要补充上下文时才调用 `brainx_candidate_facts` 或 `brainx_candidate_fit`。

把问题按事实证据、推断、建议核实动作和未知组织。优先核实硬条件、成果真实性、职责深度和最大风险；不要重复问工具已明确证实的事实。对话式准备时一次只问一个问题，正式提纲最多采用工具给出的 12 题。

姓名只用掩码，不输出联系方式、原始简历、薪资隐私或私人评价。只读、不执行写操作，不使用 SQL/Shell，不自行拼接 URL 或生成卡片链接。
