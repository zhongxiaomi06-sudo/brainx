② 产品服务层

两个产品,各自独立部署,桥接互联

BrainX(职位决策)

  • bin/ 15 CLI:sync / recommend / engage / push / outcome / replay…(天然插件化)
  • mcp/ MCP server:15 只读工具 + 承接/结果写工具
  • 推荐引擎:方向画像硬筛 + 冻结运行(200 条,可回放)
  • 承接模型:VIEW/WATCH/ACCEPT/RELEASE + commitment_actions
  • 助手 agent:src/agent/(step-3.7-flash + 技能)
  • 存储:SQLite data/brainx.db(事件账本)

reloop(人选匹配与触达)

  • FastAPI + SQLAlchemy;RDS MySQL reloop_app
  • 两阶段推荐:初筛秒出(纯本地)+ 后台 LLM 精算,缓存栈 recommend_runs
  • 双因子:活跃度(事件衰减)× 匹配度(LLM Top30 + 五维结构化)
  • 同步编排:TTC 分页拉取 → 归一化 → LLM 增强 → 按 owner 隔离
  • 飞书 OAuth 扫码登录,token Fernet 加密

可插拔;连续失败自动熔断,降级本地算法,全流程离线可跑

  • BrainX 接单自动触发,结果落 openmai_results

  • 逐人联系理由生成(并发 8)
