- 正式接入授权：允许在候选结果卡底部提供 OpenMai / SuperMai 两个继续找人按钮，并由 BrainX 自动生成排除名单。
- 未确认：真实飞书中的最终按钮视觉；候选收藏/保留与跨群上下文不属于本提交。

## 数据与动作边界

- 真实字段：`search_round`、`excluded_candidate_refs_json`、结构化候选 `candidate_ref`、项目和任务编号。
- 提取规则：OpenMai 结构化结果中的安全候选编号视为 TTC 编号；SuperMai 结果只有带官方 TTC 人才详情链接时才进入排除名单。非法、重复和无法确认的编号不使用。
- 允许动作：按钮只传 `job_id`、可选 `criteria` 和 `continue_search=true`；Agent 不能手抄、编造或直接注入排除名单。
- 失败边界：上一轮没有可确认 TTC 编号时返回 `cannot_continue`，不启动搜索、不产生费用。

## 状态证据

- 正式入口：候选结果卡底部的“OpenMai 继续找人”和“SuperMai 继续找人”。
- 后端链路：累计历史 TTC 编号 → 持久化轮次与排除列表 → 进入 OpenMai / SuperMai 提示词 → 新结果继续回原项目群。
- 发布环境与版本：仅本地代码，OpenClaw 插件版本 `1.3.3`，未发布目标环境。
- 自动验证：覆盖迁移、编号清洗与累计、跨顾问第二轮、无编号失败关闭、网关与插件契约一致、提示词传递和卡片按钮。
- 真实数据验证：未执行真实付费搜索或真实飞书按钮点击。
