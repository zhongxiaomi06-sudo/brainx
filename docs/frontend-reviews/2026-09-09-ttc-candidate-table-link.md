## 用户结论

- 已确认：筛选条件等说明可以用纯文字呈现。
- 已确认：候选人必须进入整洁表格，不能显示反斜杠、Markdown 分隔符或 `&#x20;` 等 HTML 实体。
- 已确认：每行最右侧只保留“查看人才”按钮，直接打开该候选人的 TTC 人才库详情页。
- 已确认：本链路不再发送简历或 PDF 附件。
- 未确认：新版卡片在真实飞书桌面端、手机端和窄屏中的最终视觉，以及按钮在目标环境的实际跳转。

## 正式接入与数据边界

- 正式入口：OpenMai 项目群投递 worker，以及 OpenClaw 普通回复的飞书卡片适配器。
- 真实字段：姓名、当前岗位、经验、城市、学历、核心匹配点、匹配度和稳定候选引用。
- 链接规则：仅接受 TTC 人才详情 HTTPS 链接；OpenMai 的稳定候选引用可映射为 `https://app.ttcadvisory.com/app/talent/:talentId`。无法确认 TTC 引用时显示“链接待核实”，不得伪造按钮。
- 动作规则：按钮只执行 `open_url`，不携带身份、令牌或联系方式；页面继续由 TTC 自身登录与权限控制。
- 简历规则：自动投递不再创建逐人附件话题、不下载或发送 PDF；OpenClaw 插件也不再向模型暴露发送简历工具。后端旧处理器暂时保留为兼容代码，但不在当前产品入口或插件白名单中。

## 验证证据

- 普通回复适配器覆盖带反斜杠、Markdown 表格和 HTML 空格实体的样例，断言输出为飞书 Card 2.0 原生列布局。
- OpenMai 投递覆盖逐行最右侧“查看人才”、TTC 链接安全边界、无发送简历命令和无自动 PDF。
- 当前只完成本地代码与自动测试，未发布服务器，也未完成真实飞书或真实 TTC 登录跳转验收。
