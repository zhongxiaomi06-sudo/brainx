AI-native recruiting workflow

飞书是入口，OpenClaw 是大脑，BrainX 是可信业务底座。

顾问无需安装任何软件。任意电脑或手机登录飞书，即可在同一个机器人里完成职位判断、人才匹配、推进建议与个人复盘。

02数据按人隔离

飞书身份、群范围、项目权限和字段投影逐层取交集。

03顾问保留决策

Agent 先给事实和建议，不静默外发或改变业务状态。

Operating workflows

围绕顾问任务，而不是系统模块

选择不同场景查看完整链路。每条链路都以顾问问题开始，以可执行下一步结束。

顾问发问

“今天先做什么？”或从 `/brainx` 功能首页点击。

读取本人事实

职位、项目、最近动作和数据时效只取本人授权交集。

形成判断

分开输出事实、推断、风险、待确认项与优先级。

推动下一步

给出今天可执行的三件事，顾问决定是否行动。

增量整理

worker 从授权来源拉取变化，不做无边界整库复制。

标准化事实

形成 candidate_fact_v1，保存来源、证据与质量状态。

筛选与匹配

硬条件、语义召回、多维评分和证据覆盖分开计算。

解释 shortlist

Agent 用直白语言说明为什么值得联系、风险和追问。

定目标

顾问明确当天或本周计划，不由 Agent 擅自承诺。

核对进展

读取已授权的推荐、约面、动作和结果事实。

识别差异

区分未完成、额外产出、数据缺口与流程阻塞。

调整动作

沉淀有效做法，并给出下一周期的具体行为建议。

飞书可见

管理员发布应用，把顾问加入首批可用范围。

双层绑定

OpenClaw allowlist + BrainX 身份/项目范围同时生效。

打开首页

私聊输入 `/brainx`，无需模型即可看到功能入口。

跨设备验收

手机与另一台电脑重复真实查询，证明本地零依赖。

Trust & permission

六道门，同时通过才返回数据

“机器人在群里”只代表入口存在，不代表用户获得人才库或管理视角。

Agent 可以做

  • 理解问题并选择只读业务工具
  • 从授权事实中给出匹配解释和下一步
  • 生成沟通、面试与复盘草稿
  • 把证据与不确定性清楚交给顾问

Agent 不可以做

  • 直连数据库、执行 Shell 或任意网络请求
  • 继承 Mia/York 权限或跨顾问读取
  • 暴露联系方式、简历原文和私密评价
  • 未经确认外发消息或改变业务状态
