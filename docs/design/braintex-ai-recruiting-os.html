BrainTex 工作流

从职位，到 Offer。

四个阶段，让每一步自然衔接。

点按节点，了解背后的技术逻辑。
01

职位选择与派单

顾问定方向，系统接着执行。

  1. 系统

    职位汇总

    多源聚合 · 完整快照

    +
    TTC / Radar 汇成职位事实；快照完整后再进入推荐判断。
  2. AI

    AI 分析

    六维评分 · 硬规则过滤

    +
    结合职位、关系与顾问偏好排序，冻结推荐原因，供后续回看。
  3. 顾问

    顾问选项目

    偏好记忆 · 人工确认

    +
    顾问结合推荐依据决定承接，选择与结果进入事件记录。
  4. 系统

    自动派单

    订阅触发 · 幂等执行

    +
    按订阅主动推送；顾问确认承接后，幂等建群并绑定项目权限。
确认承接 · 启动找人
02

AI 推人与人才池

同一份需求，多轮持续供给。

  1. AI

    职位画像

    职位事实 + 找人条件

    +
    合并职位要求与同群补充条件；新增条件供下一轮搜索使用。
  2. AI

    多渠道推人

    OpenMai · Reloop · SuperMai

    +
    按职位找人、检索私域人才库或按判据寻访；异步任务完成后回到项目群。
  3. 顾问

    筛选与打标

    匹配解释 · 反馈留痕

    +
    顾问核对匹配依据，确认初筛与分类；选择写入项目重点名单。
  4. 系统

    人才入池

    结构化事实 · 授权回流

    +
    通过独立授权动作加入 Reloop，保留候选来源与结构化事实。
← 调整条件 → 继续推荐继承条件 · 排除已推荐人选
初筛通过 · 进入沟通
03

触达与推荐跟进

每一次沟通，留下下一步。

  1. AI

    群内交互

    项目绑定 · 共享上下文

    +
    群与项目固定关联；机器人在授权范围内读取讨论和候选信息。
  2. 顾问

    电话沟通

    人工联系 · 纪要作证

    +
    顾问完成外部联系，把动机、顾虑和时间点录为沟通证据。
  3. 人机

    推荐跟进

    状态流转 · 到期提醒

    +
    记录当前行动、负责人和截止时间；阻塞与逾期进入提醒。
  4. 人机

    需求更新

    新条件继承 · 历史排除

    +
    客户或候选反馈改变需求时，顾问更新条件，再发起下一轮找人。
↖ 新需求 / 未匹配 → 回到找人顾问确认后发起下一轮
进入 Offer · 汇总决策上下文
04

Offer 与最佳实践

一份报告，持续积累判断。

  1. AI

    上下文汇总

    候选事实 + 项目讨论

    +
    进入候选人决策群，汇总候选事实、项目匹配与相关讨论；缺失项待确认。
  2. AI

    Offer 分析

    证据驱动 · 风险拆解

    +
    把已有证据整理为可编辑的决策报告，辅助顾问判断谈判重点。
  3. 人机

    多轮完善

    单一文档 · 追加证据

    +
    复用同一份报告，新增证据只追加；编辑稿实时问答仍待目标环境验证。
  4. 顾问

    最佳实践

    脱敏复盘 · 人工收录

    +
    顾问确认可复用经验后收录。经验回流是人工复用路径，尚非自动学习。
↶经验回流，进入下一次项目判断人工复用 · 持续积累↑
