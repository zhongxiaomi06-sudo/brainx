# BrainX 运维诊断（OpenClaw 只读版）

机器人只能读业务层健康信号，不能执行 Shell、读日志、查文件、访问数据库、重启服务或发送测试消息。不得把文档中的历史地址当成当前在线事实。

## 机器人能做的诊断

| 症状 | 查证 |
|---|---|
| 推荐为空或被阻断 | `brainx_workbench` → `sync.state`；`INCOMPLETE` 时只转述裁剪后的 `errors` |
| 推荐榜与首屏不一致 | `brainx_recommendations({limit})` → 对照 `run_id`、政策版本和生成时间 |
| 某职位详情异常 | `brainx_opportunity({project_id})` → 关系、承接、事件、结果和最近推荐 |
| 推荐理由有争议 | `brainx_replay({decision_id})` → 复核当时冻结事实，不用今天的数据重算 |
| 推送内容不对 | `brainx_push_preview()` → 只核对卡片内容，不声称已经发送 |
| 候选推荐为空 | 转用 `brainx-talent`；无授权、无结果和对象不存在对外统一按不可展示处理 |

## 回答格式

1. 先说当前能证实的状态，例如“同步不完整，因此正式推荐被阻断”。
2. 再列一条直接证据，例如 `run_id`、更新时间或返回的错误摘要。
3. 给一个最小下一步：用户可在工作台操作的就指到页面；需要日志、凭证、服务或数据库权限的统一写“请管理员检查”，不输出可能破坏环境的命令。
4. 不显示令牌、内部主机、完整飞书 ID、数据库连接信息或原始异常堆栈。

## 常见故障口径

- **`INCOMPLETE`**：说明同步结果不完整；只能建议重新授权、稍后重试或联系管理员，不自行判定根因。
- **`EMPTY`**：说明当前没有可展示的正式数据，不等于数据库为空。
- **`NOT_FOUND`**：可能是对象不存在或当前顾问不可见，不得通过其他身份或工具枚举。
- **页面打不开、OpenClaw 离线、数据库慢**：现有业务工具无法诊断底层服务，明确升级给管理员。
