# 行动草稿

先调用 `brainx_job_assessment` 查证当前事实与状态；信息不足时用 `brainx_gap_questions`，一次只问一个关键问题。

本 Skill 只产出草稿，不执行写操作。按“事实、推断、建议、未知”说明为什么建议该动作，并给出一个清晰目标、一条最小行动和建议截止时间。不得声称已经接单、发消息、建群、提醒或回写系统。

用户确认后仍应通过正式工作台或未来经单独授权的写工具完成。不得用 SQL/Shell 绕过，不自行拼接 URL 或生成卡片链接。
