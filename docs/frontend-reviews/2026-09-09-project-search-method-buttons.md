## 审核身份

- 审核日期：2026-09-09
- Storybook 场景：飞书原生项目卡片，不在 React Storybook 复制
- 对应 commit：本记录所在提交
- 审核范围：项目群内选择 OpenMai / SuperMai，以及本轮附加找人条件

## 用户结论

- 已确认：建群后提供“OpenMai 找人”和“SuperMai 找人”两个显式入口，不自动选择渠道。
- 已确认：顾问可以主动补充本轮找人条件；未补充时根据职位事实自动找。
- 已确认的目标形态：找人条件输入位于名单或项目卡片附近，并带继续找人动作。
- 当前差异：锁定版 OpenClaw 的语义化飞书卡片只稳定传递按钮值，卡片回调没有把表单输入值交给 Agent；本轮使用群消息 `找人条件：……` 作为真实可执行入口，不能把卡片内联输入框记为完成。
- 正式接入授权：允许先接入两个真实按钮、群消息条件和留空自动生成；内联输入框需待通道支持后另行审核。
- 2026-09-10 新增确认：按钮点击后不能只显示 OpenClaw 的回执表情；必须立即在群内出现“正在找人，通常需要 3–5 分钟，完成后候选人会自动发到本群”的明确文字状态。

## 数据与动作边界

- 真实字段：项目、职位、项目群、选择的找人渠道、本轮附加条件、搜索任务状态。
- 缺失字段：卡片表单值尚未进入 Agent 事件契约；真实飞书客户端按钮回调尚未验收。
- 后端依赖：OpenMai 透传附加条件；SuperMai 在项目模式下关联真实 `project_id`，留空时由职位事实生成条件；投递 worker 把结果送回原项目群。
- 允许动作：只接受已加入项目且有权访问职位的顾问触发；同一项目已有运行中或已完成的共享搜索时不重复产生找人任务。

- 发布环境与版本：本地 OpenClaw 插件目标版本 `1.3.10`；代码提交、同步与重启证据随本轮后续记录更新，未发布服务器目标环境。
- 自动验证：覆盖按钮结构、条件透传、SuperMai 空条件生成、项目关联、结果回群、跨顾问防重复触发，以及新版/旧版按钮命令的即时文字状态和消息幂等。
- 真实数据验证：未执行真实 OpenMai / SuperMai 付费搜索，也未在真实飞书客户端点击按钮。
