🧑 人工只保留这四处

  • 接单/放弃的最终决定——AI 初筛降权,人拍板
  • 推人前的话术终审——AI 起草,人审后发
  • 评估打标——AI 排序,人打标,打标即训练信号
  • offer 谈判——AI 供情报,人上场谈

💾 每一步都在沉淀数据(反哺循环)

  • 不感兴趣原话 → 推荐降权(recommendation_feedback)
  • 接/放 + 第一行动 → 承接画像(decision_events / commitment_actions)
  • 寻访简历 → 候选输入(openmai_results)
  • TopN + 推人回复 → 下一轮找谁(reloop interactions)
  • 人工事实覆盖 → 真实状态校准(manual_fact_overrides)
  • 推荐采纳/面试 → 转化漏斗(job_outcomes)
