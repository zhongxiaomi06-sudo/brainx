# Agent Commit 记录

所有 Agent 在创建代码或文档 commit 前，都必须在本文件顶部追加一条简明中文记录，并将记录与对应改动放入同一个 commit。

## 记录格式

```text
## YYYY-MM-DD｜类型(范围): 中文摘要

- 改动：说明本次提交完成了什么。
- 验证：列出已执行的测试或检查；未执行时说明原因。
```
