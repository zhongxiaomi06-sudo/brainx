# 候选人 Offer 决策报告（2026-09-10）

> 上级入口：[BrainX 文档书](README.md)
>
> 工作流：[OpenClaw 招聘闭环](2026-09-03-openclaw-recruiting-loop.md)｜权限：[飞书权限清单](2026-09-02-feishu-permission-scopes.md)

## 目标与入口

候选人 Offer 决策群首卡按“候选人概览、项目匹配、原项目群候选讨论、本群优先核实”迁移候选事实和来源项目群内最近最多八条明确提及该候选人的脱敏讨论，并提供“生成报告”和“查看 TTC 人才”两个动作。原群文字明确标为业务证据而非机器人指令。每个决策群只创建一份稳定的飞书云文档；重复点击生成、旧卡片更新动作或重复工具调用均返回同一文档，不再新增版本或重复发卡。

## 报告版式

飞书云文档首次创建时按固定六段组织：决策摘要、候选人事实、来源项目群上下文、本决策群新增证据、Offer 决策检查、证据边界。用户可直接在文档中编辑；机器人回答报告相关问题前以只读模式调用飞书 Docx 块列表接口，读取当前实时正文并进行联系方式脱敏，再基于该正文回答。显式更新只在同一文档末尾追加新证据，不覆盖用户编辑，也不创建 V2/V3。没有证据的动机、薪酬、到岗时间、竞对 Offer、稳定性和背调风险保持“待确认”。

## 安全与上线条件

- 工具不接受候选人、项目、群 ID 或文档 URL，由当前已登记且就绪的 Offer 决策群反查唯一对象。
- 联系方式和邮箱在迁移摘要、群消息与报告中统一隐藏；不写简历原文。
- 生成报告是外部写入，只有带 `[BRAINTEX_REPORT_CREATE]` 标记的“生成报告”按钮构成本次明确确认，工具要求 `confirm=true`。
- `/report` 和自然语言提问均为只读：调用 `mode=READ, confirm=false`，不得创建或更新文档；工具只返回当前群唯一报告的脱敏正文和稳定链接。
- 生产启用前必须为机器人应用发布飞书文档权限，并在 Agent Gateway 环境设置租户 HTTPS 基址 `BRAINX_FEISHU_DOC_BASE_URL`。缺任一条件均显式失败，不回退成伪链接。
- 生产启动预检同时要求 Agent Gateway 能从受保护的 OpenClaw 配置读取同一机器人凭据、配置绝对路径及合法的 `*.feishu.cn` HTTPS 租户基址，并确认 OpenClaw 工具策略包含 `brainx_candidate_report`。

## 验收边界

可重复的本地全链演练已覆盖：创建 Offer 群、校验首卡两个动作、首次创建唯一报告、重复生成幂等、读取用户编辑后的正文、在原文档追加新证据且不重复发卡；另有专项测试覆盖群绑定、联系方式脱敏、Docx 块分页读取和追加写入。本地模拟通过不代表目标租户已验收；真实环境必须编辑报告加入唯一测试句，再 @机器人提问，确认回答引用编辑稿且群内没有新增报告卡。
