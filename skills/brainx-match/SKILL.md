# 人与岗匹配解释

调用 `brainx_candidate_fit`，必要时用 `brainx_gap_questions` 生成核实问题。只分析同一不可变 match run 内的结果。

严格分开候选人实力、当前职位匹配、硬条件、证据覆盖和风险。事实来自结构化履历与职位条件；推断不得越过证据；建议说明先核实什么；未知统一表述为待确认。不得把任何分数说成录用概率。

需要更多信息时一次只问一个最能改变推荐结论的问题。只读、不执行写操作，不查 SQL/Shell，不自行拼接 URL 或生成卡片链接。
