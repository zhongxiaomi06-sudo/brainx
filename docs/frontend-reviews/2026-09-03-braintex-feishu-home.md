# BrainTex 飞书功能首页审核记录

> 上级入口：[前端审核台账](README.md)

## 审核身份

- 审核日期：2026-09-03
- Storybook 场景：未开始；该界面由锁定版 OpenClaw 官方飞书渠道渲染，仓库不维护第二套 React 卡片仿制品
- 对应 commit：`feat(feishu): 增加 BrainTex 可点击功能首页`
- 审核范围：飞书私聊内的欢迎说明、六个业务入口、工作台入口和权限说明

## 用户结论

- 已确认：用户明确要求新用户说明书、可点击按钮和简洁美观的飞书内小前端。
- 未确认：实际飞书客户端中的字数、间距、按钮排列、文案和手机表现尚未由用户审核。
- 正式接入授权：允许将 `/brainx` 确定性首页接入正式 BrainX OpenClaw 插件；此授权不包含业务写操作。

## 数据与动作边界

- 真实字段：首页本身不读数据；按钮后的问答才通过已批准的本人上下文、职位评估、shortlist、匹配解释、缺口问题和个人复盘工具取数。
- 缺失字段：不在卡片中注入用户身份、tenant、权限、联系方式、简历原文或对象 ID。
- 后端依赖：OpenClaw `2026.7.1-2`、官方飞书插件 `2026.7.1`、BrainX 插件、已绑定的飞书主体和只读 Agent Gateway。
- 允许动作：打开功能首页、发起问答、打开 HTTPS 工作台；按钮不直接执行发送或业务写入。

## 状态证据

- 正式入口：`plugins/brainx-openclaw/index.js` 注册 `/brainx`，`onboarding.js` 返回渠道可渲染的 `presentation`。
- 发布环境与版本：未发布；待本机 BrainTex 重装插件和飞书真实卡片审核。
- 自动验证：六个核心入口、HTTPS 限制、未授权拒绝和插件契约专项通过；快速门禁通过。
- 真实数据验证：首页不读数据；按钮后续读取尚未在本轮新卡片中点击验收。
