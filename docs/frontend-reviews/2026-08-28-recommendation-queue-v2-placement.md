# 2026-08-28 推荐队列 V2 卡片位置复审记录

> 上级入口：[前端审核台账](README.md)

## 审核范围

- 审核对象：Storybook `RecommendationQueueV2Review` 卡片窄屏场景。
- 用户以截图标注决策标签、详情箭头、判断区域和底部操作的位置。
- 对应 commit：本记录所在原子提交。

## 用户反馈与处理

- 决策标签从排名下方移到职位标题旁，排名单独保留在卡片起始位置。
- 右侧箭头继续作为明确的详情入口，整卡和键盘 Enter 打开详情的行为不变。
- 推荐理由、风险和可信度继续收紧间距；窄屏不再把风险与可信度强制拆成两个高占位整行区块。
- 底部动作统一靠右，次要动作在前，观察在中间，加入项目或去项目的主动作放在末位。
- 后端 `legalActions` 仍是动作显示的唯一依据；不会为了视觉稿展示后端未允许的按钮。

## 当前结论

- 截图标注已落实到 Storybook 修订稿，等待用户查看实际效果。
- 用户审核状态仍为“退回修改”，正式接入、发布和真实数据验证均未发生。
- 正式接入授权：没有。
