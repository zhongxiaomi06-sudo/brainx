## 数据与动作边界

- `opportunity_ignores` 是忽略的唯一持久事实；忽略不删除职位、旧事件或归属历史。
- 忽略会关闭当前 `MY_JOB / TEAM_SHARED` membership，并从精选盘、全部职位和我的项目共同排除；后续推荐轮在计算前继续排除。
- 正式合法动作不再返回或接受 `WATCH / UNWATCH / DISMISS`。`WATCHED / EXPIRED` 历史状态对外折叠为待开始；当前仍为 `DISMISSED` 的旧数据迁移为忽略并关闭当前归属。
- 只有存在 `OPEN / BLOCKED` 真实跟进行动时拒绝忽略；旧关注状态本身不再构成阻断。
- 显式重新加入项目会清除忽略事实，避免直接 API 操作形成“已加入但不可见”的矛盾状态。
- 飞书快捷卡片只保留签名“忽略”，不再创建关注状态。
