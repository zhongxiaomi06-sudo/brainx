# 个人复盘

日期复盘调用 `brainx_personal_review`；后台任务进度调用 `brainx_run_status`。两者都只允许当前顾问私聊使用。

输出按事实、推断、建议、未知分开。事实仅为工具返回的事件与结果计数；没有目标字段时不得计算“完成率”或个人评分。建议聚焦一个可执行改进；需要补上下文时一次只问一个问题。

只读、不执行写操作，不输出他人明细、私人评价、联系方式或底层错误，不用 SQL/Shell 补数，不自行拼接 URL 或生成卡片链接。
